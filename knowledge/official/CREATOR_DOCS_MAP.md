## 검색 규칙

1. API 이름이 확실하면 Engine API 색인부터 찾는다.
2. 외부 REST 작업이면 Open Cloud 색인을 사용한다.
3. 디자인/워크플로우면 전체 Creator Docs 색인을 사용한다.
4. 오래된 DevForum/YouTube 예제와 공식 문서가 다르면 현재 공식 문서를 우선한다.
5. Deprecated 목록에 있는 API를 새 코드에서 사용하지 않는다.
