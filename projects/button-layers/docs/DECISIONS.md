# Button Layers — Decisions

Accepted material decisions as of 2026-10-13.

## D-001 — Classic Button Incremental
Launch stays focused instead of adding combat/pets/mining/crafting/trading.

## D-002 — Launch chain ends at Ascension
`Cash → Multiplier → Rebirth → Ultra Rebirth → Prestige → Ascension`.
Do not predesign endless Mega/Omega layers before data justifies them.

## D-003 — 50 Main Buttons
20 Multi / 12 Rebirth / 8 Ultra / 6 Prestige / 4 Ascension.
Higher denominations compress proven lower-tier repetition.

## D-004 — Occupancy-repeat Cost buttons
Cost buttons can repeat while the player remains validly on the plate. Reset buttons fire once per entry.

## D-005 — Automation is Main Progression
Automation starts around Ultra and expands upward. It is not paid convenience required to make the free game tolerable.

## D-006 — Achievements/Secrets are optional power
48 Achievements + 8 Secrets provide goals and modest bonuses but never gate the main path.

## D-007 — Five Areas map to progression layers
Foundation → Rebirth → Ultra → Prestige → Ascension. Areas differ in spatial grammar, not recolor only.

## D-008 — Clean Layered Arcade art direction
Stylized readable geometry, controlled emissive accents, strong landmarks, tier-specific color + symbol + shape.

## D-009 — Server authority
Valuable state is server authoritative. Manual and Automation share transaction/reset code.

## D-010 — Release candidate is a validation state
Code/content existence does not equal completion. Save, security, device, visual, route and performance QA are required.
