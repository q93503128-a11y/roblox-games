# Button Layers

Status: **design complete / implementation not started / Studio validation pending**

`Button Layers` is a classic Roblox Button Incremental focused on fast, readable progression rather than unrelated simulator systems.

Core chain:

```text
Cash → Multiplier → Rebirth → Ultra Rebirth → Prestige → Ascension
```

Launch design:
- 50 Main Buttons
- 5 Areas
- 48 internal Achievements
- 8 Secrets
- Button Collection
- Quick Travel
- Auto Multi / Rebirth / Ultra / Prestige
- Stats & Records
- versioned save/load
- desktop/mobile UI
- server-authoritative economy
- release QA gates
